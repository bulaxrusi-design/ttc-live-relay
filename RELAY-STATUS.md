# TTC Live Relay

Repository initialized for TTC Bridge v3.

- `control/` is reserved for ChatGPT-issued commands.
- `state/` is reserved for phone screenshots, status, and TTC reports.
- No command is preloaded because every v3 command must use the current phone-generated `session_id`.
